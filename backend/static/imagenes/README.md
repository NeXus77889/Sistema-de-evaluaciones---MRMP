# Logo Institucional

Coloca aquí el logo de la institución con uno de estos nombres:

- `logo.svg` (preferido — vectorial, se ve nítido en cualquier tamaño)
- `logo.png` (alternativa — mínimo 256×256 px recomendado)

El sistema buscará primero `logo.svg` y luego `logo.png`.
Si no encuentra ninguno, se usará el logo por defecto (`static/img/uepmrmp-logo.svg`).
